# ADR-018 · S-18 · Chuẩn hóa Phiên bản Framework & Trình duyệt Client Hỗ trợ
- Trạng thái: Đã chốt
- Người viết: TV4
- Liên quan: E-02, C-19 · 1.2, 2.1, 5.1 · CR-18

## Bối cảnh
SRS v1.0.0 ghi danh mục trình duyệt hỗ trợ quá cũ (lỗi E-02) và nhận định sai lầm "Node.js chỉ cần lúc build" (lỗi C-19), trong khi Next.js Standalone Mode bắt buộc có Node.js Runtime ở Production.

## Quyết định
- Stack Công nghệ Chuẩn hóa:
  - Frontend: Next.js 16.x (App Router, Standalone Mode), React 19, Tailwind CSS v4, TypeScript 5.x. Node.js 22 LTS Runtime trên Docker.
  - Backend: .NET 10.0 SDK / C# 13, Minimal APIs, MediatR v12.x (giấy phép MIT).
  - CSDL & Cache: PostgreSQL 16.x (unaccent, pg_trgm), Redis 7.2.x.
- Danh mục Trình duyệt Hỗ trợ Tối thiểu:
  - Google Chrome / Microsoft Edge: Version 111+
  - Mozilla Firefox: Version 128+
  - Safari (macOS / iOS): Version 16.4+
  - Bỏ hỗ trợ hoàn toàn Internet Explorer và Safari < 16.0.

## Hệ quả
- Tận dụng tối đa sức mạnh của Next.js 16 App Router & Tailwind CSS v4.
- Đảm bảo môi trường thực thi giữa Local và Docker Production hoàn toàn đồng nhất.

## Phương án dự phòng
Thêm healthcheck kiểm tra Node.js version trong Dockerfile của Frontend (node -v), nếu < v20.0.0 sẽ ngắt quá trình build container ngay lập tức.
