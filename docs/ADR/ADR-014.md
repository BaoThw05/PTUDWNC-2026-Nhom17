# ADR-014 · S-14 · Sinh Dynamic Sitemap bằng Next.js App Router & Maintenance Jobs Hangfire
- Trạng thái: Đã chốt
- Người viết: TV4
- Liên quan: C-16, G-05 · FR-JOB-003, NFR-SEO-001, 3.6, 5.1 · CR-14

## Bối cảnh
SRS v1.0.0 yêu cầu Hangfire gọi Google Search Console Sitemap Ping API – endpoint này đã bị Google khai tử từ 06/2023 (lỗi C-16). Việc sinh file xml tĩnh ở Backend rồi đẩy lên MinIO gây lỗi thời sitemap và phức tạp cấu hình Nginx.

## Quyết định
Tách bạch vai trò Frontend SEO và Backend Maintenance Jobs:
- Frontend (Next.js App Router):
  - Sinh Sitemap động qua app/sitemap.ts (Dynamic Sitemap) query danh sách công thức Published và danh mục từ Backend API với ISR revalidate = 3600 (1 giờ).
  - Khai báo app/robots.ts trỏ tới Sitemap: https://culinaryblog.com/sitemap.xml.
  - Bỏ hoàn toàn Google Ping API.
- Backend (Hangfire Recurring Jobs):
  - Job 1 (01:00 AM UTC): Dọn dẹp Refresh Tokens hết hạn/revoked quá 30 ngày (TV1).
  - Job 2 (02:00 AM UTC): Dọn dẹp file mồ côi trên S3 Storage (TV3).
  - Job 3 (03:00 AM UTC): Dọn dẹp công thức trong Thùng rác bị xóa mềm quá 30 ngày (TV2).

## Hệ quả
- Triệt tiêu lỗi phụ thuộc API khai tử của Google.
- Sitemap luôn cập nhật tự động qua Next.js ISR mà không làm nặng Backend.
- Hangfire tập trung đúng vai trò dọn dẹp rác hệ thống ngầm.

## Phương án dự phòng
Nếu Next.js ISR revalidate gặp sự cố mạng tạm thời với Backend: Route app/sitemap.ts sẽ dùng cache cũ trong 1 giờ tiếp theo cho tới khi khôi phục kết nối.
